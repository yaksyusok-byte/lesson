# Мастерская рабочих листов

Редактор материалов по русскому языку для 5–9 классов. Работает без регистрации, backend и внешнего ИИ. Текст, ответы и комментарии полностью задаёт преподаватель.

## Запуск

Нужен Node.js 22 или новее. В этой папке:

```bash
npm ci
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`). Не открывайте исходный `index.html` двойным щелчком: ему нужен Vite.

## Создать и скачать лист

1. При первом запуске открыт демонстрационный лист для 6 класса с теорией и пятью разными заданиями. **Новый лист → С нуля** создаёт собственный проект.
2. Слева укажите класс, тему, заголовок, подзаголовок и поля. Добавьте блоки. Стрелками или перетаскиванием изменяйте порядок.
3. Выберите блок слева или нажмите карточку на странице. Справа измените содержание, цвет, отступы, размер шрифта, строки для ответа или таблицу.
4. Центр показывает настоящие пропорции А4. Длинные материалы переносятся автоматически; доступны страницы и масштаб.
5. Введите ответы и комментарии в нижней части редактора. **С ответами** показывает преподавательскую версию.
6. **Скачать PDF** предлагает ученический вариант или вариант с ответами. Файл создаётся в браузере: текст и линии векторные, кириллические шрифты встроены.

**Вставить материалы** добавляет текст в выбранный тип блока без переформулирования. Разбивку на блоки выполняет преподаватель. Для пропусков используйте `______`. Схемы, варианты ответа и соответствия редактируются через отдельные поля.

## Сохранение

- Черновик автоматически сохраняется в этом браузере после изменений.
- **Сохранить** добавляет или обновляет проект в **Моих листах**.
- **Дублировать лист** создаёт независимую копию с новыми идентификаторами.
- JSON переносит весь проект, включая ключи. **Не передавайте JSON ученикам**, если в нём есть ответы: для них предназначен ученический PDF.
- Данные не отправляются в сеть. Очистка данных браузера удаляет проекты: скачивайте JSON для резервной копии. Ошибка хранилища выводится пользователю, не выдаётся за успешное сохранение.

## Возможности и ограничения

12 типов: заголовок, теория, задание, пропуски, таблица, классификация (2/3 группы), соответствия, выбор ответа, чтение, строки, схема и иллюстрация. До 300 блоков; таблицы до 6 столбцов и 200 строк. Проект JSON — до 2 млн символов. Порядок строк таблиц и формулировки не меняются автоматически. Огромная строка таблицы переносится частями с пометкой продолжения. Поля 10–28 мм, текст 9–18 пт.

PDF и SVG-предпросмотр используют одну раскладку и одинаковые метрики Open Sans. Переносы — только оформление; исходные строки остаются в проекте. Длинные слова переносятся по символам, пустые строки сохраняются. Ответы исключены из ученической раскладки, а не просто скрыты CSS.

## Будущий ИИ

Режим **По теории** сохраняет авторский материал. Генерация без подключения не выполняется и сообщает об отсутствии сервиса. Интерфейс будущего адаптера — `src/ai.ts`. Реальный адаптер должен обращаться к серверу с безопасно хранящимися ключами, проверять ответ по `blockSchema` и показывать результат преподавателю для редактирования. Сейчас запросов к ИИ нет.

## Проверки

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

При системном Chromium задайте `WORKSHOP_CHROMIUM=/путь/к/chromium` перед `npm run test:e2e`. Тесты проверяют все типы блоков, длинные тексты/ячейки, сохранность источника, изоляцию ключей, импорт, редактирование, перестановку, таблицы и реальные скачивания PDF.

## Публикация

```bash
npm run build
```

Содержимое `dist/` размещается на статическом хостинге. Относительные пути работают в подпапке `/lesson/`.

Готовая ветка `workshop-site`: в GitHub включите **Settings → Pages → Deploy from a branch → workshop-site → /(root)**. После публикации адрес — `https://yaksyusok-byte.github.io/lesson/`. Наличие ветки не означает, что Pages уже включён.

## Архитектура

`model.ts` — данные, валидация, демонстрация; `layout.ts` — страницы и элементы; `pdf.ts` — векторный экспорт; `fonts.ts` — шрифты и метрики; `components/` — формы и предпросмотр; `storage.ts` — сохранение, JSON и скачивание. `tests/` содержит тесты раскладки и браузерных сценариев.

Open Sans: Apache 2.0, лицензии в `public/fonts`. Примеры реального экспорта — в `examples/`.
